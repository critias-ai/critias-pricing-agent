# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

We want a welcoming, harassment-free space for everyone, whatever their background or experience. Be respectful, assume good intent and keep criticism about the work.

## Reporting

Report unacceptable behaviour to **hello@critias.ai**. Every report is reviewed and handled in confidence. Maintainers may remove, edit or reject contributions, and may ban contributors who break this code, following the Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
