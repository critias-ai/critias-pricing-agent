# Presentation path repair and downstream audit — 9 October 2026

Workflow **1.0.14** fixes the presentation handoff from the last live test and hardens the following visual-verification and publication steps. The unchanged first presentation response from that run now passes the rebuilt controller. **91 focused tests**, typecheck and build pass. No new paid evaluation was submitted; the historical run remains `verified-partial` and its charts are not retroactively approved.

## Root cause and fix

The renderer returned an absolute HTML path, while its ledger recorded a workspace-relative path. Handoff compared these literally. Figure and capture references had the same mismatch; figure arrays also had to match the producer's order exactly.

The shared presentation validator now resolves existing absolute, workspace-relative, stage-relative and run-relative references safely, then compares canonical paths with recorded render/preview evidence. It preserves escape/symlink rejection, file hashes, preview chart count, complete figure inventory and desktop/narrow inspection of every chart. Figure order comes from the render ledger. It returns a new canonical object without mutating the producer response. The HTML is always included in downloadable files.

An input `report.json` is still rejected as a rendered report. The diagnostic now names the recorded HTML to use, rather than asking vaguely for another render. The schema and bundled visualization guidance distinguish these files and describe controller-owned metadata.

## Remaining limits

The saved 390px charts still have clipped titles/endpoint labels and an overlapping missing-cost annotation. The local repair did not rewrite their generated figures or manufacture a visual approval. A fresh model could request a genuine presentation correction or fail to complete within the unchanged limits.

Two renders/two previews and the one shared correction allowance remain bounded. The existing worker charges a second render to that allowance; a later visual correction may therefore be unavailable. This is an explicit remaining limit, not another path mismatch, and was not relaxed. The controller must keep returning a verified partial numerical result when presentation cannot be approved.

Successful local transport and publication tests do not establish that a live model will produce complete, correctly checked, readable charts. No downstream failure can be ruled out universally; the deterministic failures above are now covered, while new live visual approval, mobile layout and broader acceptance remain unproven.
